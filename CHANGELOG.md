# 0.1.1

- Исправлен отсутствовавший WebChromeClient: Android теперь показывает confirm/alert/prompt. Раньше confirm автоматически возвращал false (SSH и сценарии отменялись), а prompt возвращал null (аудиофайл отбрасывался после выбора).
- Убрано обязательное ручное название трека. Название читается у провайдера Android, поддержан выбор нескольких файлов и пропуск дубликатов.
- Файлы получают постоянное разрешение чтения. Если провайдер выдаёт только временный доступ, приложение сохраняет приватную копию (до 512 МБ на файл).
- Добавлена кнопка проверки SSH-входа без выполнения команд. Ошибки аутентификации, адреса, порта и тайм-аута объясняются в выводе.
- Пароли SSH и passphrase сохраняются без удаления крайних пробелов.
- Добавлены статусы SSH и обновляемый вывод команды, явный EOF stdin, keepalive и заранее созданный known_hosts.
- Изменение ориентации не пересоздаёт Activity во время выбора файла/подключения.
- Для выбора аудиофайлов увеличено время ожидания ответа до 15 минут.

Причина поведения WebView подтверждается документацией Android: https://developer.android.com/reference/android/webkit/WebChromeClient#onJsConfirm(android.webkit.WebView,%20java.lang.String,%20java.lang.String,%20android.webkit.JsResult)
